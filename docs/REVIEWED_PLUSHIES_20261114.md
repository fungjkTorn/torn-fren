## Apply only this release

`deploy/scripts/install_reviewed_plushies.py --apply` validates the installed foundation and Monkey model against reviewed semantic fingerprints. It preserves each cohort's existing scheduler signature and flags by applying narrow hooks, stages the six actual item CLIs with injected modules and one disposable SQLite backup, waits for existing workers, then updates only the first-ten/challengers/next-six source folders. Existing launch paths and timers are retained. The input copy is removed afterward; one small code rollback directory remains. Unknown installed revisions stop before source mutation. Repeating a successful update verifies the installed source/feed and returns without reinstalling.

The installer must run on the VM as root. It does not deploy the website, bot or unrelated GitHub changes. Public feed policy/freshness checks must pass for all six items. On failure after cutover, original code is restored and existing timer states are recovered, without rewinding any ledger or database. GitHub merge alone does not update the VM.
